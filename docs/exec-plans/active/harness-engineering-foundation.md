# Harness Engineering Foundation

## Goal

Make Alpha Research operable by Codex through repo-local knowledge, deterministic local dashboard state, structured debug payloads, and executable validation scripts.

## Acceptance Criteria

- Agent map and docs exist.
- Dashboard can run with seeded local harness data.
- Build and test scripts validate harness contracts.
- Run debug endpoint exposes machine-readable triage context.
- QA script can smoke-check the dashboard in harness mode.
