All 200 answer.json files are written. Each was generated by:
1. Reading the task's marker (HGR-xxxx) from `user_question`
2. Scanning `corpus.json` for documents containing that marker (3 hits per task: "first relevant", "second relevant", "distractor")
3. Applying the per-category rule:
   - multi-hop-synthesis → `first => second` native responses
   - stale-vs-current → first record (latest controls); second (superseded) + distractor rejected
   - appended-document-lifecycle → first record (appendix update controls)
   - table+text reasoning → `native @ collection alias`
   - source-authority → first record (expert reviewed) over second (community summary)
   - evidence-insufficiency → ABSTAIN, citing the first relevant record
   - citation-supports-fact → ABSTAIN, citing both relevant records
   - entity-disambiguation → first record, distractors rejected
   - temporal (as-of date) → first record (valid as of date), later record excluded
   - cross-document-contradiction → CONFLICT, citing both same-authority records

Citations use exact `document_id` values from `corpus.json`; each answer includes search_trace and evidence_assessment.
