# Cleveland Museum Collection Shape

This experiment implements the first study spec generated by the Humanities Dataset Registry: `What A Museum Collection Looks Like When It Becomes Data`.

It uses the Cleveland Museum of Art Open Access API to show what acquisition, creation-date, department, collection, culture, and public-domain/image-availability patterns become visible in a structured museum dataset.

## Research Question

What acquisition, creation-date, department, geography/culture, and medium patterns become visible in a fully open museum API?

## Unit Of Analysis

Artwork metadata record.

## Runbook

```bash
node docs/experiments/cleveland-museum-collection-shape/scripts/run-pipeline.mjs --limit=5000 --page-size=1000
```

Or run step by step:

```bash
node docs/experiments/cleveland-museum-collection-shape/scripts/fetch-artworks.mjs --limit=5000 --page-size=1000
node docs/experiments/cleveland-museum-collection-shape/scripts/build-report.mjs
node docs/experiments/cleveland-museum-collection-shape/scripts/check-readiness.mjs
```

The scripts write:

- `data/raw/api/<run-date>/`
- `data/processed/artworks.json`
- `data/processed/artworks.csv`
- `data/processed/department-counts.csv`
- `data/processed/creation-century-counts.csv`
- `data/processed/acquisition-decade-counts.csv`
- `data/processed/culture-counts.csv`
- `reports/report.html`
- `reports/result.json`
- `reports/work.md`
- `reports/public-draft.md`
- `reports/readiness.md`
- `reports/readiness.json`
- `reports/pipeline-run.json`

## Publication Standard

This study can support a first essay about the shape of one open museum collection. It should not generalize to museums as a whole without comparison datasets.
