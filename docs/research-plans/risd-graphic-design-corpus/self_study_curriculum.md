## How To Use This

1. Treat each module as a studio brief, not a lecture topic.
2. Produce visible artifacts every week: sketches, type studies, prototypes, publications, motion tests, or systems.
3. Write a critique memo after each artifact using the recovered constraints and skill signals.
4. Revise the artifact once before moving on; the revision is part of the assignment.
5. Keep unknowns explicit when the corpus lacks a schedule, rubric, or complete brief.
