Dataset Briefing

This public housing affordability demo combines HUD Fair Market Rent benchmarks with Census/ACS income and rent-burden context. It is shaped for ranking current demo-county pressure from FY2024 rent benchmarks and ACS/CHAS burden context.

Known-Good Questions

QuestionKnown-good output
Where is rental affordability pressure highest in the demo counties?Travis County, TX ranks first on cost-burden and severe-burden rates; Miami-Dade County, FL has the highest FY2024 two-bedroom FMR and a severe-share ratio above 57 percent.
Which county pairs high benchmark rent with high severe-burden share?Miami-Dade County, FL combines the highest FY2024 two-bedroom FMR in the demo with a severe-share ratio above 57 percent.
Which counties should a housing policy analyst inspect first?Travis County, Miami-Dade County, Hillsborough County, and Maricopa County are ranked in the structured result with burden and FMR fields preserved.
What limitation should accompany county comparisons?Do not describe the live production result as a full 2018-2024 change estimate; the verified run combines FY2024 FMR with ACS/CHAS 2016-2020 renter burden context.

Golden Workflow

  1. Codex receives the housing affordability request.
  2. The agent lists datasets and selects housing-affordability.
  3. The agent drafts a remote run plan and asks for approval.
  4. The remote run executes while the dashboard shows live status.
  5. Final artifacts appear and the agent summarizes from them.
