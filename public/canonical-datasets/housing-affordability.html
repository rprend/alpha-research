Dataset Briefing

This public housing affordability demo combines HUD Fair Market Rent benchmarks with Census/ACS income and rent-burden context. It is shaped as a county-year panel for ranking where rental affordability pressure worsened from 2018 to 2024.

Known-Good Questions

QuestionKnown-good output
Where did rental affordability pressure worsen most from 2018 to 2024?Miami-Dade County, FL ranks first with pressure_score 91.4 and rent_to_income_ratio increasing from 0.38 to 0.49.
Which counties show high FMR growth but moderate severe rent burden?Travis County, TX is flagged as high-growth/moderate-burden because FMR growth is 39 percent while severe_rent_burden_share remains below the fixture median.
Which metro outliers should a housing policy analyst inspect first?Miami-Fort Lauderdale, Phoenix-Mesa, and Tampa-St. Petersburg are the top three metro contexts by pressure_score.
What limitation should accompany county comparisons?Compare changes and ranks, not exact affordability levels, where ACS renter-income estimates are suppressed or noisy.

Golden Workflow

  1. Codex receives the housing affordability request.
  2. The agent lists datasets and selects housing-affordability.
  3. The agent drafts a remote run plan and asks for approval.
  4. The remote run executes while the dashboard shows live status.
  5. Final artifacts appear and the agent summarizes from them.
