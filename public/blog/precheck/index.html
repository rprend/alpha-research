Precheck

Do you get the same type of code review from the same people? Do you put up a PR and go through the same back and forths with the same person every time? Precheck does that. Precheck audits a specific reviewer, discovers common themes between the comments they leave, creates a skill based on this, allowing you to preempt their reviews before they happen, and ship faster.

Precheck runs locally. Run it inside a GitHub repository, choose a reviewer, and it uses local GitHub CLI and your local Claude Code / Codex CLI to help you work faster.

Instructions

Give your coding agent (Codex, Claude) this instruction:

Install and run Precheck in this repo: https://alpharesearch.nyc/precheck/install.sh. Set up a review for <REVIEWER'S NAME>

After the skill has been created:

Run a review of my branch as <REVIEWER'S NAME>. Make the changes that they would suggest.
