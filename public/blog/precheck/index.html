Precheck

Are you getting the same type of code reviews from the same people? Precheck helps with that. Precheck audits a specific reviewer in a git repo, checks for commonalities between the comments they leave, then creates a system to preempt their reviews before they happen.

Code review feedback often has a shape. One reviewer catches missing lifecycle tests. Another notices when an abstraction hides the actual boundary where correctness matters. Another asks for narrower migrations, better fixtures, or clearer product states. The useful thing is not just that a reviewer "cares about tests." The useful thing is knowing the specific review moves they make and the concrete examples those moves came from.

Precheck is a small local tool for turning that history into a reviewer-specific preflight system. Run it inside a GitHub repository, choose a reviewer, and it uses local GitHub CLI and Claude Code authentication to build a profile from that reviewer's prior PR comments.

Use it from a coding agent

Give your coding agent this instruction:

Install and run Precheck in this repo: https://alpharesearch.nyc/precheck/install.sh. Set up a review for <PERSON'S NAME>

What happens

Setup and collection Local CLI, local auth, GitHub review history
1 Install Download the Precheck CLI from alpharesearch.nyc into ~/.local/bin/precheck.
2 Detect repo Read git origin, identify the GitHub owner and repository, and verify gh and Claude Code auth.
3 Select reviewer Use --reviewer, interactive selection, or recent PR activity to choose the reviewer to model.
4 Collect history Fetch recent PR reviews and inline comments through gh api, then save raw JSON locally.

Then Claude Code runs four local synthesis passes. Each pass writes an artifact that the next pass reads.

Reviewer synthesis Evidence first, then patterns, then final instructions
1 Evidence map Extract review moves, mechanisms, distinctions, failure modes, triggers, and representative cases.
2 Pattern synthesis Create reviewer patterns with 2-5 historical examples for each high-value pattern.
3 Anti-generic filter Remove patterns that are merely topics and rank the rest by mechanism, evidence, and predictive value.
4 Final artifacts Write a reviewer profile, reusable Claude instructions, and a copy-paste future review prompt.

The output

Precheck writes everything under ~/.precheck/repos/<owner>__<repo>/reviewers/<reviewer>/. The raw GitHub data stays in raw/. The synthesized reviewer system goes into synthesized/.

  • evidence-map.md: evidence-first map of review moves and concrete examples.
  • reviewer-patterns.md: synthesized reviewer patterns with representative examples.
  • filtered-patterns.md: anti-generic ranked patterns.
  • reviewer-profile.md: final predictive reviewer profile.
  • claude-reviewer.md: reusable Claude Code review instructions.
  • review-prompt.md: prompt for checking a future branch before review.

Why it works

The tool is intentionally evidence-first. It does not ask an agent to guess a personality profile from a few comments. It first builds an evidence map, then synthesizes review patterns, then rejects generic claims that do not have a mechanism, trigger, quote, or reusable pre-review action.

The most important artifact is the representative-example set. A useful reviewer model should be able to say, "this new diff resembles those three prior cases," not merely "this reviewer likes clean code." That is what makes the profile operational for a coding agent.

Install manually

curl -fsSL https://alpharesearch.nyc/precheck/install.sh | sh
precheck --reviewer <github-login>
