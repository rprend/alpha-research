Privacy

Before you connect a dataset or sign in, here is the current Alpha Research data-handling scope in plain English.

Collected today

Basic site delivery and security logs, plus sign-in and run metadata only after you use the dashboard or CLI.

Not collected on this page

No public-site accounts, no upload form, and no hidden dataset submission from reading this page.

Questions or sensitive use cases

Email ryan@zenobiapay.com before sharing sensitive data.

Scope and last updated

This page describes the current public marketing site, the hosted dashboard sign-in flow, and the RESEARCH CLI handoff as of May 1, 2026.

What happens if you only browse the public site

  • This site does not offer a public account signup form, dataset upload form, or public contact form.
  • Reading the public site does not send Alpha Research a dataset, prompt, or research document from your machine.
  • The site can still produce normal web delivery and security records such as IP address, browser or device metadata, requested URL, timestamp, and similar request diagnostics through hosting infrastructure.
  • No separate ad-tech or product analytics integration is described in this repository for the public site today.

Cloudflare and operational logging

Alpha Research is served through Cloudflare-managed infrastructure. That means standard request, performance, and security telemetry may exist at the infrastructure layer even when you do not submit a dataset.

Alpha Research does not publish a fixed retention window for those infrastructure logs in this repository today. If your use case depends on specific retention, residency, or contractual review, ask before using the product.

What changes when you sign in or use the CLI

  • The dashboard and RESEARCH CLI use an authenticated site session so the product can associate datasets, runs, artifacts, and saved sessions with your account email.
  • When you create a dataset through the product, Alpha Research stores dataset metadata, run records, saved artifacts, and related session history in the control plane so you can inspect and resume work later.
  • The CLI page already explains the key handoff: install and sign-in alone do not upload your dataset, but creating a dataset can upload the source file you choose for remote research execution.

Retention and practical limits

  • Alpha Research stores operational run state and artifacts so the dashboard can show history, logs, and outputs attached to the same work.
  • This repository does not publish a self-serve deletion workflow or fixed retention schedule for dashboard records yet.
  • If you should not place a dataset into hosted storage without a specific retention agreement, do not upload it until you have reviewed the use case with us directly.

How to ask before bringing sensitive data

For privacy, retention, or sensitive-data questions, email ryan@zenobiapay.com. Include the dataset type, whether the source is regulated or confidential, and what constraints matter most so we can answer concretely before you proceed.
