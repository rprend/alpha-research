Bring your own dataset

Install the RESEARCH CLI, sign in, and point it at your own data. This page shows the exact install command, what you need before you run it, what data leaves your machine, and where to find the dataset and run after the CLI starts working.

Install

Paste this into a macOS or Linux terminal with git, node, and npm installed.

git node npm 
curl -fsSL https://raw.githubusercontent.com/zenobia-pay/alpha-research/codex/initial-substrate/scripts/install_alpha_research.sh | bash

1. Install

Run the install command above. It clones the CLI, installs dependencies, builds it, and puts a research command in ~/.local/bin.

2. Authenticate

Run research. The CLI opens alpharesearch.nyc/cli/login in your browser and signs you in with your Alpha Research site session.

3. Point At Dataset

Tell the CLI what the dataset is called, whether it is local files or remote sources, and what question you want answered.

Required inputs

  • A terminal with git, node, and npm.
  • A dataset path or source URL.
  • A short description of what the data covers and the first question you want to answer.

Privacy and trust

  • Installing and signing in does not upload your dataset.
  • When you create a dataset, Alpha Research stores dataset metadata and uploads the source file you choose so it can build the remote research environment.
  • The dashboard will show the dataset, deploy run, logs, and saved artifacts attached to that work.

What Happens Next

What happens next

Use these commands after install so you can verify the CLI is working and know where the result will appear.

research help

research

Expected result:
- The CLI opens your browser for Alpha Research sign-in if you are not already signed in.
- After you describe a dataset, Alpha Research creates the dataset record, starts a deploy run, and returns the dataset id, run id, and current status.
- Open the dashboard to watch status, inspect logs, and review artifacts.
